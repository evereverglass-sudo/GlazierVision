\# GlazierVision - Measure Glass from Photo with SAM 3.1



Problem: Glaziers drive 2hrs to measure broken windows. 30% wrong cuts = $500 loss.



Solution:

\- SAM 3.1 segments window frame

\- Reference card (credit card) for scale -> inches calculation

\- Llama Vision classifies glass type

\- Spark agent generates L\&I compliant quote



Stack: SAM 3.1, Llama 4 Vision, Muse Spark, Muse Wonder
